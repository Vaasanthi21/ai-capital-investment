1. Executive Summary

This implementation plan defines the architectural blueprint for connecting the Creative OS Blog Publisher with the Standalone Blogs Page (/blogs) in the AI Capital Investment application.

Currently, the Blogs page renders a static set of institutional research articles. This project introduces a dynamic event-driven storage and synchronization layer (blogStorage.ts) that allows logged-in investors to compose and publish custom articles in Creative OS and immediately view them in the /blogs feed across active browser sessions.

3. Data Schema Specification

export interface BlogArticle {
  id: string;             // Unique ID: `user-blog-${timestamp}`
  title: string;          // Article Title
  category: string;       // 'AI & Tech' | 'Tax Strategy' | 'Macro Strategy' | 'Crypto'
  author: string;         // Logged-in investor's name
  date: string;           // Formatted publication date
  readTime: string;       // Estimated read time (e.g. "5 min read")
  abstract: string;       // Short summary snippet
  image: string;          // Cover image URL
  imageAlt: string;       // Accessibility alt text
  content: string[];      // Paragraph array
  isUserCreated: boolean; // Flag identifying investor-created articles
}

4. Technical Component Specifications

Component 1: Storage Layer (src/lib/blogStorage.ts)

  • getUserBlogs(): BlogArticle[]: Reads and parses investor-published articles from LocalStorage.
  • saveUserBlog(blogData): BlogArticle: Appends new article with timestamp, ID, and dispatches real-time window events.
  • deleteUserBlog(id: string): void: Option for users to remove their published posts.

Component 2: Creative OS Publisher (src/components/CreativeOSPublisher.tsx)

  • Form fields for Title, Category dropdown, Abstract snippet, Content body, and Cover Image URL.
  • Form submission handler that validates required inputs, saves data to storage, and redirects to /blogs.

Component 3: Dynamic Feed Controller (src/components/StandaloneBlogPage.tsx)

  • Initializes state with [...getUserBlogs(), ...standaloneBlogArticles].
  • Subscribes to blog-published and storage events for instant, cross-tab feed synchronization.
